# Contributing to CyberVault

Thank you for your interest in contributing! This knowledge base thrives on community contributions and improvements.

## How to Contribute

### 1. **Add New Content**
- Create well-structured markdown files
- Follow existing formatting conventions
- Include practical examples and commands
- Add relevant emojis for quick scanning
- Link related topics

### 2. **Improve Existing Content**
- Fix typos, clarify confusing sections
- Update outdated information
- Add missing examples or edge cases
- Expand incomplete guides

### 3. **Report Issues**
- Found an error or broken link?
- Create an issue with details
- Include the file path and what needs fixing

## Content Guidelines

### File Structure
```
Topic/
├── Overview section with emoji header
├── Step-by-step instructions
├── Tables for reference
├── Code examples (bash, python, etc.)
└── Related resources/links
```

### Formatting Standards
- Use **bold** for important terms
- Use `code blocks` for commands and code
- Use tables for comparisons
- Use blockquotes `>` for warnings ⚠️ and tips 💡
- Link to related files: `[Related](../path/to/file.md)`

### Example Section Header
```markdown
## Topic Name

### Overview
Brief explanation...

### Key Concepts
| Concept | Meaning |
|---------|---------|

### Examples
\`\`\`bash
command here
\`\`\`
```

## Ethical Guidelines

✅ **DO**
- Share defensive security knowledge
- Help others learn responsibly
- Include authorization requirements
- Focus on CTF and lab environments
- Cite sources and tools

❌ **DON'T**
- Share active exploits without context
- Include real-world target information
- Post credentials or API keys
- Encourage unauthorized access
- Violate laws or terms of service

## Pull Request Process

1. **Fork** the repository
2. **Create a branch** for your changes
3. **Make your edits** following guidelines
4. **Test** examples and links
5. **Submit PR** with description of changes
6. **Review** feedback and iterate

## Questions?

- Check existing issues/discussions
- Review similar content for style guidance
- Ask before starting major changes
