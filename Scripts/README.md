# 🚀 Scripts & Automation

## Overview

Useful scripts and automation tools for cybersecurity work.

## Using Kali Linux

Instead of custom scripts, we focus on leveraging built-in Kali Linux tools:

- **nmap** - Network scanning
- **dig** - DNS queries
- **curl/wget** - Web requests
- **wireshark** - Packet analysis
- **metasploit** - Exploitation framework
- **hashcat** - Password cracking
