# CyberVault

A personal cybersecurity knowledge base, cheat sheets, and practical reference library for ethical hacking, offensive security, and defensive hardening.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![GitHub repo size](https://img.shields.io/badge/size-knowledge%20base-blue)](https://github.com/markehospes-art/CyberVault)
[![Status](https://img.shields.io/badge/status-public%20knowledge%20base-orange)](https://github.com/markehospes-art/CyberVault)

CyberVault is built for learning, structured note-taking, and quick lookup during CTFs, labs, and authorized security work.

## What is inside

- Cheat sheets for common offensive and defensive workflows
- Structured knowledge modules by topic
- Handy scripts and technique references
- Practice links for CTF and lab platforms

## Important legal and ethical reminder

This repository is for educational use only.

Use this material only in:
- your own lab environment
- authorized engagement with written permission
- CTF or training environments
- systems you own or are explicitly authorized to test

Do not use these notes to target systems or environments without permission.
