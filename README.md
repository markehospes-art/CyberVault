## 📖 Overview

CyberVault is a structured, reference-friendly knowledge base designed for:
- **Security practitioners** preparing for pentests and CTFs
- **Students** building foundational cybersecurity knowledge
- **Teams** maintaining consistent security practices

Everything is organized by topic with quick-access cheat sheets, hands-on walkthroughs, and defensive security principles.

## 🚀 Quick Start

### I'm new to cybersecurity

1. Learn the fundamentals: [Networking](Knowledge/Networking/README.md)
2. Get comfortable with Linux: [Linux Fundamentals](Knowledge/Linux/Linux-Fundamentals.md)
3. Explore reconnaissance: [Nmap Cheat Sheet](CheatSheets/Nmap.md)
4. Practice on labs: [TryHackMe](https://tryhackme.com) • [Hack The Box](https://www.hackthebox.com)

### I need a quick reference

- **Scanning network?** → [Nmap](CheatSheets/Nmap.md)
- **Stuck on privilege escalation?** → [Priv Esc Checklist](CheatSheets/Privilege-Escalation-Checklist.md)
- **Testing web apps?** → [Burp Suite](CheatSheets/Burp-Suite.md) or [SQL Injection](CheatSheets/SQL-Injection-Quick-Ref.md)
- **Need a reverse shell?** → [Reverse Shells](CheatSheets/Reverse-Shells.md)

### I'm preparing for a CTF

1. Review [CTF Methodology](Knowledge/CTF/CTF-Methodology.md)
2. Use cheat sheets for quick command reference
3. Check [Scripts](Scripts/README.md) for exploitation techniques

## ⚖️ Legal & Ethical Use

**This repository is for educational use only.** Use this material only in:
- ✅ Your own lab environment
- ✅ Authorized security engagements with written permission
