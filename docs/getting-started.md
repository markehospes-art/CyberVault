# Getting Started with CyberVault

CyberVault is a structured cybersecurity knowledge base for learning, lab work, and CTF preparation. It is organized into four main layers:

- [CheatSheets](../CheatSheets/README.md) for command references and quick lookups
- [Knowledge](../Knowledge/README.md) for conceptual learning
- [Scripts](../Scripts/README.md) for step-by-step workflows
- [MOCs](../MOCs/README.md) for structured study paths

## Recommended first steps

1. Read [README.md](../README.md) for the repository overview.
2. Open [HOME.md](../HOME.md) for the landing page.
3. Use [INDEX.md](../INDEX.md) to navigate the full contents.
4. Start with the networking path in [MOCs/Networking.md](../MOCs/Networking.md).
5. Move into [Knowledge/README.md](../Knowledge/README.md) for deeper explanations.

## Suggested flow

- Beginners: Networking -> Linux -> Web Security -> CTF practice
- Red team learners: Recon -> Web -> Exploitation -> Privilege Escalation
- Defensive learners: Monitoring -> Hardening -> Logging -> Incident response

## Safety and scope

This repository is intended for:

- authorized lab work
- personal learning and study
- CTF and training platforms
- defensive review and security hardening

It should not be used for unauthorized access or malicious activity.
