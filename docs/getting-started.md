# 🚀 Getting started

CyberVault is a knowledge base designed for cybersecurity study, home labs, CTF prep, and defensive review. It is not a project application or a running service; it is a structured learning library.

## Recommended path

If you are new to the repo:

1. Read the root [README.md](../README.md)
2. Review the learning roadmap in [study-roadmap.md](study-roadmap.md)
3. Start with the fundamentals in [../Knowledge/README.md](../Knowledge/README.md)
4. Use [../CheatSheets/README.md](../CheatSheets/README.md) when you need a quick command or payload lookup
5. Use [../Scripts/README.md](../Scripts/README.md) when you want a workflow or methodology

## What each layer is for

### CheatSheets
Use this for fast lookup while working in a lab or assessment environment. These are quick references for tools, commands, payloads, and operational tasks.

### Knowledge
Use this for conceptual understanding: how protocols, operating systems, attacks, and defenses actually work.

### Scripts
Use this for step-by-step methodologies and guided execution plans.

### MOCs
Use this for structured learning tracks that build from basics into more advanced topics.

## Suggested order

- Networking
- Linux fundamentals
- Web security
- Active Directory
- Password attacks and credential abuse
- Post-exploitation and privilege escalation
- Defense and hardening
- CTF methodology
