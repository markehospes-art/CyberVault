# 🏢 Active Directory Attack Methodology (MOC)

Structured learning path for AD enumeration and exploitation.

---

## Phase 1: Fundamentals (Week 1-2)

- AD architecture
- Domain concepts
- Organizational units
- Group policies
- Trust relationships

## Phase 2: Enumeration (Week 3-4)

- User enumeration
- Computer enumeration
- Group membership
- Service principal names
- Delegations

## Phase 3: Reconnaissance (Week 5-6)

- BloodHound data collection
- PowerView enumeration
- Domain trust mapping
- Finding admin accounts
- Identifying attack paths

## Phase 4: Exploitation (Week 7-8)

- Kerberoasting
- AS-REP Roasting
- Pass-the-hash
- Pass-the-ticket
- Golden ticket
- Silver ticket

## Phase 5: Post-Exploitation (Week 9-10)

- Domain persistence
- Lateral movement
- Privilege escalation
- Data exfiltration

- BloodHound
