# 🗺️ Networking - Map of Contents (MOC)

## Overview

This MOC provides a structured learning path for networking fundamentals. Follow the topics in order for optimal understanding.

---

## 📚 Learning Path

### Foundation (Week 1-2)

**1. [OSI Model](../Knowledge/Networking/OSI-Model.md)** ⭐ START HERE
- Understand the 7-layer model
- Learn how data flows through layers
- Key concepts for all networking
- **Time:** 15-20 minutes

**2. [IP Addressing](../Knowledge/Networking/IP-Addressing.md)**
- IPv4 and IPv6 address formats
- Private vs public addresses
- Address classes and ranges
- **Time:** 20-25 minutes

**3. [Subnetting](../Knowledge/Networking/Subnetting.md)**
- Divide networks efficiently
- Subnet masks and CIDR notation
- Real-world examples
- **Time:** 25-30 minutes

---

### Protocols (Week 2-3)

**4. [TCP vs UDP](../Knowledge/Networking/TCP-UDP.md)**
- Connection-oriented vs connectionless
- When to use each protocol
- Header structures
- **Time:** 15-20 minutes

**5. [DNS](../Knowledge/Networking/DNS.md)**
- Domain name resolution
- DNS queries and records
- How domains work
- **Time:** 20-25 minutes

---

### Web Layer (Week 3-4)

**6. [HTTP](../Knowledge/Networking/HTTPS-TLS.md)**
- Hypertext Transfer Protocol basics
- Request/response cycle
- Status codes and headers
- **Time:** 20-25 minutes

**7. [HTTPS/TLS](../Knowledge/Networking/HTTPS-TLS.md)** ⭐ SECURITY CRITICAL
- SSL/TLS encryption
- Certificate handling
- Secure communication
- **Time:** 25-30 minutes

---

## 📊 Prerequisites

✅ Basic computer networking knowledge
✅ Understanding of internet basics
✅ Willingness to learn concepts in order

## 🎯 Learning Goals

After completing this MOC, you will understand:

- ✅ How networks communicate
- ✅ The role of each OSI layer
- ✅ How to design and subnet networks
- ✅ When and why to use TCP vs UDP
- ✅ How DNS translates domain names
- ✅ How HTTP/HTTPS works
- ✅ How TLS secures communication
- ✅ Practical networking concepts

## 💡 Tips for Success

1. **Read in order** - Each topic builds on previous knowledge
2. **Take notes** - Write down key concepts
3. **Use diagrams** - Draw the OSI model, subnets, etc.
4. **Practice calculations** - Work through subnet examples
5. **Test knowledge** - Try to explain concepts to others
6. **Lab work** - Practice with real tools (nmap, ping, etc.)
